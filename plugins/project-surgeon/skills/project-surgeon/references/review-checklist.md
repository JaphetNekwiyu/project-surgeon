# Review checklist

- [ ] Read AGENTS.md, docs, scripts, package and workspace definitions.
- [ ] Inventory all packages, entry points, routes, jobs and dynamic import paths.
- [ ] Check git status; preserve existing changes.
- [ ] Record existing test, typecheck, lint and build results safely.
- [ ] Run read-only scanner and investigate false positives.
- [ ] Trace duplicate code semantics and apparent dead code dependencies.
- [ ] Audit APIs, query patterns, performance, errors and authorization.
- [ ] Identify protected finance, auth and database areas.
- [ ] Make only isolated, low-risk source changes if cleanup was requested.
- [ ] Validate with targeted and full safe tests; review diff.
- [ ] Report evidence, file paths, uncertainty, edits and remaining risks.
